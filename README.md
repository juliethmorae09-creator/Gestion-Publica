## ▶️ Cómo ejecutar

1. Descarga o clona el proyecto.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en el navegador.
4. Para una experiencia profesional, instala la extensión **Live Server** en VS Code.
5. Haz clic derecho sobre `index.html` y selecciona **Open with Live Server**.

## 🐙 Subir a GitHub

Desde la terminal de VS Code:

```bash
git init
git add .
git commit -m "Primer commit - sitio web Gestión Pública"
git branch -M main
git remote add origin URL_DE_TU_REPOSITORIO
git push -u origin main
```

Reemplaza `URL_DE_TU_REPOSITORIO` por la URL de tu repositorio de GitHub.
